Supported job-name patterns for `sbatches/golan-trainmodels.sbatch`

Backbone prefix
- Default backbone is ConvNeXt Small: use the patterns below as-is.
- Prefix any supported pattern with `convnext_base_` to launch ConvNeXt Base.
- Prefix any supported pattern with `convnext_large_` to launch ConvNeXt Large.
- Examples:
  - `l2_16_init1` -> `convnext_small_l2_16_init1`
  - `convnext_base_l2_16_init1` -> `convnext_base_l2_16_init1`
  - `convnext_large_l2_16_init1` -> `convnext_large_l2_16_init1`
  - `v1clean_linf_8_init1` -> `convnext_small_v1_clean_linf_8_init1`
  - `convnext_base_v1clean_linf_8_init1` -> `convnext_base_v1_clean_linf_8_init1`
  - `convnext_large_v1clean_linf_8_init1` -> `convnext_large_v1_clean_linf_8_init1`

Legacy standard training
- `baseline_init<INIT>`

Legacy Madry adversarial training
- `linf_<EPS>_init<INIT>`
- `l2_<EPS>_init<INIT>`
- `l1_<EPS>_init<INIT>`

Legacy TRADES adversarial training
- `linftrades_<EPS>_init<INIT>`
- `l2trades_<EPS>_init<INIT>`
- `l1trades_<EPS>_init<INIT>`

GradNorm
- `gradnorm_l1_<EPS>_init<INIT>`
- `gradnorm_l2_<EPS>_init<INIT>`

V1 standard training
- `v1clean_init<INIT>`
- `v1noise_init<INIT>`

V1 Madry adversarial training on V1 features
- `v1clean_linf_<EPS>_init<INIT>`
- `v1clean_l2_<EPS>_init<INIT>`
- `v1clean_l1_<EPS>_init<INIT>`

V1 TRADES adversarial training on V1 features
- `v1clean_linftrades_<EPS>_init<INIT>`
- `v1clean_l2trades_<EPS>_init<INIT>`
- `v1clean_l1trades_<EPS>_init<INIT>`

Rejected / unsupported job names
- `gradnorm_<EPS>_init<INIT>`  (must specify `gradnorm_l1` or `gradnorm_l2`)
- `v1clean_gradnorm_*`
- `v1noise_gradnorm_*`
- `v1noise_linf_*`
- `v1noise_l2_*`
- `v1noise_l1_*`
- `v1noise_linftrades_*`
- `v1noise_l2trades_*`
- `v1noise_l1trades_*`

Notes
- `<EPS>` is the configured epsilon value encoded in the job name.
- `<INIT>` is the experiment/init id encoded after `init`.
- Backbone prefixes are optional and only recognized at the start of the job name.
- Base uses the same batch-size policy as Small.
- Large uses 3/4 of the selected Small/Base batch size.
- V1 adversarial jobs launch with `attack_domain=v1_feature`.
- V1 noisy adversarial jobs are intentionally blocked.
